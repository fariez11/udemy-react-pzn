# Membuat Project
  - npm create vite@latest react-router -- --template react
  - pastikan menggunakan versi react terbaru
  
  > Menambah Library React Router
    - npm i react-router


# Setup
  - berbeda dengan MPA, ketika membuat SPA, kita cukup membuat satu halam html sebagai entry point (titik masuk) semua request
  - nanti, penentuan komponen mana yang akan ditampilkan, diurus oleh React Router
  
  > Browser Router
    - ketika menggunakan React Router, saat membuat melakukan render komponen menggunakan React, kita bisa bungkus aplikasi React kita menggunaka komponen Browser Router
    - https://api.reactrouter.com/v7/functions/react_router.BrowserRouter.html


# Routing
  - adalah pemetaan antata URL, path dan komponen yang akan ditampilkan 
  - untuk melakukan Routing, kita bisa menggunakan komponen <Routes>
  - https://api.reactrouter.com/v7/functions/react_router.Routes.html
  - dan untuk pemetaan tiap Routing nya, kita bisa gunakan komponen <Route>
  - https://api.reactrouter.com/v7/functions/react_router.Route.html
    

# Nested Route
  - saat nanti kita membuat routing, kadang terdapat routing yang dimiliki prefix yang sama
  - jika kita harus membuat satu per satu, maka akan tidak efektif ketika pembuatan kode nya
  - untungnya, React Router mendukung Nested Route
  - kita bisa menggunakan komponen Route di dalam komponen Route, dan secara otomatis Route path diatasnya akan digunakan sebagai prefix path untuk child Routenya 

  > Index Route 
    - komponen Route memiliki attribut spesial bernama Index
    - Atribut ini digunakan sebagai default halaman Index
    - ini biasanya digunakan untuk path awal, misal /, atau untuk nested path /data/...
    - contoh sebelumnya, saat kita membuka /data, maka tidak ada komponen yang ditampilkkan, kita bisa tampilkan komponen yang kita mau dengan menggunakan Route Index

# Outlet
  - saat kita membuat halaman Web, kadang beberapa halaman memiliki Layout yang sama, misal header dan footer nya sama, namun isi contentnya berbeda
  - sebenarnya kita bisa menggunakan JSX untuk melakukan ini dengan menggunakan children
  - namun, react router memiliki cara yang lebih mudah, kita bisa membuat Route dengan component yang digunakan sebagai Layout
  - lalu kita bisa tambahkan Route di dalamnya yang digunakan sebagai children 
  - namun, kita tidak menggunakan children Prop lagi, melainkan menggunakan Component Outlet
  https://api.reactrouter.com/v7/functions/react_router.Outlet.html

# Route Param 
  - saat kita membuat URL path, kadang kita tidak membuat Path yang statis kadang kita membuat Path yang dinamis
  - misal kita ingin menambahkan id / kode pada Path, misal product/123, dimana 123 adalah id dari product
  - di React Router, kita juga bisa lakukan itu dengan menambah tanda : (titik dua) diikuti dengan nama param, misal /products/:id, id dianggap sebagai parameter dinamis
  - jika kita menggunakan /product/123, maka 123 akan dianggap sebagai data parameter id

  > useParams()
    - saat kita membuat Path yang dinamis, biasanya kita ingin mendapatkan informasi Path yang dinamis tersebut
    - seluruh dynamyc param yang terdapat di URL Path secara otomatis akan disimpan dalam object, dan kita bisa mengambilnya menggunakan function useParams()
    - https://api.reactrouter.com/v7/functions/react_router.useParams.html
    - misal, sekarang kita akan coba tambahkan useParams() pada komponen ProductDetail
  
  > Multiple Route Param
    - kita bisa menambahkan dynamyc param pada Path lebih dari satu 
    - yang penting kita gunakan nama dynamyc param yang berbeda, misal : /user/:userId/address/:addressId
    - maka kita bisa dapatkan informasi userId dan addressId di Object hasil dari useParams()
